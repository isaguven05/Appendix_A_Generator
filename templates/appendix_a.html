5 How to Name Your Image Files

The tool reads the filename of each image to work out which provider it belongs to and whether it is an RF Schematics slide or a GA Building slide. Follow the rules below before uploading — any file that can't be matched will be highlighted in red in the preview and skipped.
🏷️ Step 1 — Include the provider name in the filename

The provider name must appear somewhere in the filename (not case-sensitive). The app recognises all of these formats:

ProviderAccepted filename formatsExample filenames
EE EE_Station - ...
EE - Station - ... 		EE_Temple - Design plan1.jpeg
EE - Lambeth North - Design plan1.jpeg
THREE THREE_Station - ...
Three - Station - ...
THREE - Station - ... 		THREE_Temple - Building 1 - Midway.jpeg
Three - Lambeth North - Design plan2.jpeg
VODAFONE VODA_Station - ...
VODAFONE_Station - ...
Vodafone - Station - ...
Station_voda1 - ... 		VODA_Temple - Design plan3.jpeg
Vodafone - Lambeth North - Building 1 - Platforms.jpeg
Lambeth North_voda1 - Design plan5.jpeg
VMO2 VMO2_Station - ...
VMO2 - Station - ...
Station_VMO2NEW - ... 		VMO2_Temple - Design plan4.jpeg
Lambeth North_VMO2NEW - Design plan6.jpeg
📄 Step 2 — The slide type is detected automatically from the filename

Once the provider is identified, the app checks the filename for these keywords to decide which template slide to use:

Slide typeHow it's detectedExamples
📐 RF Schematics Filename contains Design plan or Design_plan EE - Lambeth North - Design plan1.jpeg
THREE_Temple - Design plan2.jpeg
🏢 GA Building Everything else — the last part of the filename becomes the slide title EE_Temple - Building 1 - Midway.jpeg → title: "Midway"
THREE_Temple - Building 1 - Platform 1&2.jpeg → title: "Platform 1&2"
⚠ Files that will be skipped (shown in red in the preview below):
  • Files with no provider name anywhere — e.g. Lambeth North - Building 1 - Basement.jpeg
  • Files with only suffixes like _DONE, _NEW, _FINAL and no provider name

👉 Fix this by adding the provider name — e.g. rename to EE - Lambeth North - Building 1 - Basement.jpeg
