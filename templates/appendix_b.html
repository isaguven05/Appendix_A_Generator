4 Metadata Placeholder Reference

The following placeholders will be replaced in your Appendix B templates. Make sure your template files contain these exact strings.

PlaceholderReplaced with
<<DATE>>Your Date input
<<AUTHOR>>Your Author input (full name)
<<CHECKED>>Your Checked input (full name)
<<APPROVED>>Your Approved input (full name)
<<ADDRESS>>Your Station Address
<<P01>>Your P01 Date input
<<P02>>Same value as <<DATE>>
<D>Author initials (e.g. IG)
<C>Checked initials
<A>Approved initials
<P>Provider code — EE→2, VODAFONE→3, VMO2→4, THREE→5

All providers share a single template: templateB.pptx — placed in the app folder on the server. The only per-provider difference is the <P> provider code substitution above.

5 Image Filename Guide

The app reads the filename of each image to decide which provider it belongs to and whether it becomes an RF Schematics slide or a GA Building slide. Follow the rules below — unmatched files are flagged in red and skipped.

🏷️ STEP 1 — Provider must appear somewhere in the filename

The app accepts any of these formats (case-insensitive):

ProviderAccepted filename patternsExamples
EE EE_Station - ...
EE - Station - ...		 EE_Temple - Design plan1.jpeg
EE - Lambeth North - Design plan1.jpeg
THREE THREE_Station - ...
Three - Station - ...		 THREE_Temple - Building 1 - Midway.jpeg
Three - Lambeth North - Design plan2.jpeg
VODAFONE VODA_Station - ...
VODAFONE_Station - ...
Vodafone - Station - ...
Station_voda1 - ... 		VODA_Temple - Design plan3.jpeg
Vodafone - Lambeth North - Building 1 - Platforms.jpeg
VMO2 VMO2_Station - ...
Station_VMO2NEW - ... 		VMO2_Temple - Design plan4.jpeg
Lambeth North_VMO2NEW - Design plan6.jpeg
📄 STEP 2 — Slide type is detected from the filename

After the provider is identified, the app checks for these keywords:

Slide typeRuleExamples
📐 RF Schematics Filename contains Design plan EE - Lambeth North - Design plan1.jpeg
THREE_Temple - Design plan2.jpeg
🏢 GA Building Everything else — last part of the name becomes the slide title EE_Temple - Building 1 - Midway.jpeg → title: "Midway"
THREE_Temple - Building 1 - Platform 1&2.jpeg → title: "Platform 1&2"
⚠️ Files that WILL be skipped (shown in red below)
  • Files with no provider keyword anywhere in the name — e.g. Lambeth North - Building 1 - Basement.jpeg
  • Files tagged only with _DONE, _NEW, _FINAL etc. with no EE / THREE / VODA / VMO2 in the name

👉 Add the provider name anywhere in the filename to fix this — e.g. rename to EE - Lambeth North - Building 1 - Basement.jpeg
