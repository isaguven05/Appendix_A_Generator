1 RF Predictions Report

This is the Output Maps Report.pptx produced by the RF prediction tool — the file that contains all the coverage maps for every provider. The tool reads it automatically and sorts the maps into the correct slides.
What happens next: the tool reads every slide, identifies which provider, technology, frequency and building each map belongs to, then builds one polished PPTX per provider — with slides sorted in the correct order automatically.
Output: one PPTX per provider  |  more than one provider → downloaded as a .zip file

6 Providers & Logos

The tool generates a separate document for each provider listed here. Enter each provider name exactly as it appears in the RF Predictions Report (e.g. EE, VODAFONE, VMO2, THREE). You can also upload a logo image for each provider — it will be placed on the operator page of that provider's document.
⚠ Remove any providers not present in the report — if a provider name isn't found in the uploaded report, no document will be generated for it and it will be silently skipped.
